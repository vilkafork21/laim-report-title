# g-aiva-title

Модуль генерации HTML-шапки отчёта о валидации ML-модели. Принимает отчёт о разработке и набор метаданных модели, указанных вручную через UI, и возвращает готовую HTML-страницу с титульным оформлением.

## Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `model_id` | string | ID модели |
| `model_version_id` | string | ID версии модели |
| `model_version_name` | string | Название версии модели |
| `significance` | string | Степень значимости (например `С`) |
| `dev_block` | string | Блок разработчика |
| `owner_block` | string | Блок владельца |
| `validator` | string | ФИО ответственного валидатора |
| `validation_date` | string | Дата валидации (например `02.12.2025`) |
